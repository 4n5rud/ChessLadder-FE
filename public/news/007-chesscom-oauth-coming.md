# ♟️ Chess.com OAuth 연동 준비 중!

ChessLadder에 새로운 기능이 추가될 예정입니다!

기존 Lichess 연동에 추가로 **Chess.com OAuth 로그인**이 지원됩니다.

## 🎯 변경 예정 사항

- ✨ **메인 페이지**: Lichess + Chess.com 듀얼 로그인 버튼
- ✨ **헤더 메뉴**: Chess.com 로그인 옵션 추가
- ✨ **프로필 통합**: Lichess와 Chess.com 계정 연동 지원
- ✨ **통계 통합**: 두 플랫폼의 체스 통계를 함께 확인 가능

이제 더욱 많은 체스 플레이어들이 ChessLadder를 통해 자신의 실력을 향상시킬 수 있을 것 같습니다!

계속해서 더 나은 서비스를 제공하기 위해 노력하겠습니다. 감사합니다! 🙏
